# Chattappinlamning
En enkel chattapp byggd med ASP.NET Core, Razor Pages, JavaScript och SignalR. Användaren kan ansluta med ett användarnamn och sedan skicka meddelanden till alla anslutna klienter.

## Instruktioner för att köra projektet lokalt
### Förutsätter att du har .NET SDK, Visual Studio eller Visual Studio Code installerat och en webbläsare.

1. Klona projektet från GitHub.
2. Öppna projektet i Visual Studio.
3. Starta applikationen med HTTPS-profilen (körs på https://localhost:7048).
4. Öppna chatten i två webbläsarfönster för att testa med flera användare.

OBS: Om HTTPS-certifikatet inte är betrott behöver du köra följande kommando i terminalen:

```bash
dotnet dev-certs https --trust
```

### AI-användning
AI har använts främst för hjälp med styling av sidan men även en del för hjälp med kodning, förklaringar och kommentarer.
AI har aldrig använts blint utan all kod den har gett har gåtts igenom och den har fått förklara samtliga val.
